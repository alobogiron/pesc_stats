                                                        1. 2012-2015. AdaptativeSensorObf: Arcabouço de Ofuscação de Código e Proteção de Dados Adaptativo para Redes de sensores sem fio
                                                          Descrição: proteção de dados adaptativo, eficiente, resiliente e furtivo para RSSF para melhorar a segurança das Rede de Sensores Sem Fio. Nossa proposta é dita ser adaptativa pois busca adaptar em tempo de execução o conjunto de controles de segurança durante a execução de aplicações nos sensores, de forma a assegurar a disponibilidade, a confidencialidade e a integridade dessas aplicações. Nossa proposta é dita ser eficiente pois as técnicas de ofuscação aplicadas em um programa aumentam o grau de dificuldade para realizar a engenharia reversa de um programa e é dita ser resiliente pois as transformações realizadas por ele resistem a ataques que buscam extrair dados automaticamente pois essas transformações são difíceis de serem identificadas. Por fim, nossa proposta é furtiva pois garante que um programa ofuscado não seja identificado como um programa ofuscado. Em outras palavras, um programa ofuscado de forma furtiva fortalece o nível de proteção de um programa ofuscado, pois os atacantes devem colocar mais esforço para descobrir quais técnicas de ofuscação foram utilizadas..                                                           Descrição: Com o advento dos medidores inteligentes com software embarcado surgiram funcionalidades diversas tais como telemetria, pré-pagamento e desligamento remoto. Estas inovações tecnológicas trouxeram desafios distintos para a segurança da informação além de serem alvos mais visados por atacantes.
