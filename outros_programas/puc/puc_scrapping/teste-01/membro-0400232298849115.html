Marco Antonio Casanova

Marco A. Casanova é Pesquisador do Instituto Tecgraf e colaborador do Programa de Pós-graduação em Informática da Pontifícia Universidade Católica do Rio de Janeiro - PUC-Rio. Formou-se em Engenharia Eletrônica pelo Instituto Militar de Engenharia (1974), e obteve o Mestrado em Ciências em Informática pela PUC-Rio (1976) e o Mestrado (1978) e Doutorado (1980) em Matemática Aplicada pela Harvard University. Foi Coordenador de Pós-Graduação (2005-2007), Diretor (2007-2011), e Professor Titular (2015-2025) do Departamento de Informática da PUC-Rio, e Coordenador Central de Planejamento e Avaliação da PUC-Rio (2012-2025). Sua pesquisa concentra-se em modelagem conceitual de bancos de dados, construção de sistemas de gerência de bancos de dados, e aplicacões de Large Language Models - LLMs. Pelo conjunto das contribuições, em julho de 2012, recebeu o Prêmio Mérito Científico da Sociedade Brasileira de Computação.                                       12. 2008-2010. Métodos e Técnicas para Alinhamento de Esquemas Conceituais
                                        Descrição: Alinhar dois esquemas conceituais consiste em definir um relacionamento entre os conceitos dos dois esquemas de tal forma que, intuitivamente, conceitos relacionados possuem o mesmo significado. Alinhamento de esquemas conceituais é um problema fundamental na mediação de consultas e na criação de armazéns de dados. Um primeiro enfoque para alinhamento de esquemas, chamado de enfoque sintático, consiste em alinhar conceitos tomando como base sugestões sintáticas, como os nomes e tipos de dados das propriedades. Este enfoque depende da suposição implícita de que proximidade sintática implica em proximidade semântica. O segundo enfoque, chamado de enfoque semântico (extensional ou baseado em instâncias), utiliza as próprias instâncias armazenadas nos bancos de dados para gerar hipóteses sobre o alinhamento dos conceitos. Este enfoque é mais robusto do que o enfoque sintático, mas aplica-se apenas a esquemas sem grande complexidade estrutural. Tanto o enfoque sintático quanto o enfoque semântico operam a posteriori, no sentido de que tentam alinhar esquemas conceituais pré-existentes, que tipicamente não foram projetados para tal. Contrastando com esta situação, podemos definir o enfoque a priori, baseado na premissa de que, se o banco de dados deverá ser integrado com outros bancos de dados (através de um mediador ou de um armazém de dados), então o seu esquema conceitual (ou o esquema exportado) deverá ser baseado em um esquema conceitual de referência para a área de aplicação a que o banco se refere. Tendo em vista que o enfoque sintático foi largamente explorado, este projeto concentra-se no desenvolvimento de técnicas, seguindo o enfoque semântico a posteriori, para alinhamento de taxonomias utilizadas na classificação de objetos em bancos de dados distintos e para alinhamento de esquemas conceituais em geral. O projeto investiga ainda métodos para criação de esquemas conceituais de referência através do alinhamento e reuso de fragmentos de ontologias.. Situação: Concluído; Natureza: Pesquisa.                                       13. 2008-2010. Infraestrutura de Metadados para Objetos Científicos
                                        Descrição: Em diversas áreas do conhecimento, investigação científica hoje depende da estreita interação entre grupos de pesquisa geograficamente dispersos, detentores de dados, processos ou tecnologia complementares entre si. Esta forma de investigação necessita portanto de uma infra-estrutura de serviços computacionais que permita um acesso fácil, seguro e coordenado a dados e processos geograficamente distribuídos. Dados científicos são provenientes de fontes tão diversas quanto aceleradores de partículas, sensores a bordo de satélites, seqüenciamento de genomas, por exemplo, ou derivados de outros dados através de processos de análise. São são representados de várias formas ? estruturada, semi-estruturada e não-estruturadas ? e estão armazenados em bancos de dados especializados, repositórios institucionais, ou mesmo nos computadores pessoais dos pesquisadores. Os processos de análise são tipicamente combinados em processos mais complexos, modelados como workflows. As tarefas de localizar, avaliar a utilidade, extrair, integrar ou combinar estes dados e processos requerem técnicas e ferramentas específicas, endereçando desde gerência de metadados até métodos de otimização para execução de workflows, em um ambiente distribuído de computação. Além disto, tais técnicas e ferramentas não devem ser específicas para um particular domínio de aplicação. Todas as peculiaridades do domínio devem ser isoladas em uma descrição formal, que as ferramentas interpretam para realizar o seu trabalho. Neste contexto, este projeto destina-se a: 1) Desenvolver métodos, técnicas, ferramentas e software frameworks para catalogação semi-automática de metadados de objetos científicos. 2) Desenvolver métodos, técnicas, ferramentas e software frameworks para mediação de acesso aos metadados de objetos científicos. 3) Desenvolver métodos, técnicas, e software frameworks para compartilhamento de resultados entre comunidades de usuários trabalhando em experimentos virtuais..                                       14. 2007-2014. Cooperativas de Fontes de Dados
                                        Descrição: Este projeto visa desenvolver métodos e ferramentas para criação de cooperativas de fontes de dados, definidas como conjuntos de fontes de dados autônomas, interligadas através de mediadores que oferecem consulta e atualização dos dados. Uma fonte de dados é um termo neutro para designar um conjunto de dados encapsulados por um sistema de gerência de banco de dados ou por uma aplicação especificamente desenvolvida para tal. Os métodos de projeto propostos para cooperativas de fontes de dados enfatizarão a definição de padrões estendíveis para organização e acesso aos dados, simplificando a criação de mediadores. As ferramentas de consulta propostas incluirão mecanismos de flexibilização que substituem o conceito de resposta exata pelo conceito de resposta pelo melhor esforço. As ferramentas de atualização propostas também incluirão mecanismos para processamento flexível de workflows, resgatando a noção de transação, na medida do possível. Os métodos e ferramentas propostos manterão a liberdade das fontes de dados, inerente à noção de cooperativa. Os métodos e ferramentas propostos terão impacto tanto no contexto aberto da Web, expondo a semântica das fontes de dados de forma processável por software, quanto no contexto de corporações cujos dados residem em uma variedades de fontes relativamente autônomas. O primeiro contexto corresponde à visão da Web semântica, com a diferença de que a semântica tornada visível é a do conjunto de dados armazenados em uma fonte de dados. O segundo contexto é essencialmente o de uma federação de bancos de dados, exceto que elimina à priori os problemas oriundos da heterogeneidade semântica dos dados..
